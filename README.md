# 公基研习册

这是一个面向河南定向选调公共基础知识复习的静态网站。网站会在构建时自动读取 `公共基础知识复习资料` 文件夹中的 Markdown 文件，渲染复习正文、每日真题、答案解析和全局搜索索引。

## 本地运行

需要 Node.js 20 或更高版本。首次运行：

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址（通常为 `http://localhost:5173/`）。提交前可执行：

```bash
pnpm test
pnpm build
pnpm preview
```

如果电脑上使用 npm，也可以将上面的 `pnpm` 替换为 `npm`：`npm install`、`npm run dev`、`npm test`、`npm run build`。

`pnpm build` 会先校验资料格式，再执行 TypeScript 检查和生产构建。

## 新增每日资料的详细规则

每新增一个复习日，只需要在 `公共基础知识复习资料` 中新增一个 `.md` 文件。文件名建议使用 `Day02-复习资料与真题.md`、`Day03-复习资料与真题.md` 这样的格式；网页实际按照 YAML 中的 `day` 数字排序，因此文件名中的数字和 YAML 必须保持一致。

每日文件必须在最顶部使用 YAML 元数据，前后各一行 `---`：

```yaml
---
kind: day
day: 2
title: 公共基础知识复习资料
---
```

字段规则如下：

- `kind` 必须写成 `day`，表示每日复习资料。
- `day` 必须是大于 0 的整数；不能与已有文件重复。
- `title` 必须是非空文本，用于页面元信息，建议保持“公共基础知识复习资料”。
- 当前首版只支持单选题，每道题必须有 A、B、C、D 四个选项。
- 每日正文中必须出现 `## 今日真题练习（N道）` 二级标题；括号也可使用半角形式 `## 今日真题练习(N道)`。

正文可按以下结构书写。知识点部分完全使用普通 Markdown；题目部分请保留标题和字段格式：

```markdown
---
kind: day
day: 2
title: 公共基础知识复习资料
---

# Day 2 · 公共基础知识复习资料

> 今日重点模块：经济学（C）+ 法律（E）

## 模块C：经济学

### 1. 供给与需求

这里写知识点、表格、列表或引用。

## 今日真题练习（1道）

### 第1题

**下列关于市场机制的说法，正确的是（ ）**

A. 选项一
B. 选项二
C. 选项三
D. 选项四

**【答案】B**

**解析：** 这里写答案解析，可继续使用 Markdown。

---

## 今日复习小结

这里写当天总结或明日预告。
```

题目校验规则：

1. 题目标题必须是 `### 第N题`，其中 `N` 为数字，且同一文件不能重复题号。
2. 题干必须是题目块中的第一行加粗文本，例如 `**题干内容**`。
3. 选项必须严格按 `A.`、`B.`、`C.`、`D.` 四行提供。
4. 答案必须使用 `**【答案】B**` 格式，答案字母只能是 A、B、C、D 之一。
5. 解析必须使用 `**解析：**` 或 `**解析:**` 开头，并且后面有非空内容。
6. `## 今日复习小结` 等下一个二级标题之后的内容会作为答题区下方的普通 Markdown 展示。

每个每日资料中的三级标题（例如 `### 1. 二十大的主题`）会被识别为知识点，并在标题右侧显示星标收藏按钮。收藏后会出现在左侧“我的收藏”中；再次点击星标或从知识点处取消收藏即可移除。收藏数据只保存在当前浏览器的 `localStorage` 中，不会上传到服务器，清理浏览器站点数据后会被清空。

练习题下方的按钮可在“显示答案”和“关闭答案”之间切换。关闭答案只收起当前题的答案与解析，不会清除已经选择的选项；点击整套“答案解析”后，所有题目会进入提交锁定状态。

大纲文件是资料目录中唯一一个 `kind: overview` 文件：

```yaml
---
kind: overview
title: 河南定向选调公共基础知识复习计划
---
```

## GitHub Pages 部署

仓库工作流位于 `.github/workflows/deploy.yml`。创建 GitHub 仓库并推送代码后，在仓库的 **Settings → Pages → Source** 中选择 **GitHub Actions**。以后每次向默认分支推送新的 Markdown，Actions 会自动重新构建并发布站点。

网站使用 Hash 路由和相对资源路径，适用于 `https://用户名.github.io/仓库名/` 形式的项目站点。
